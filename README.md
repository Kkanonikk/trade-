# Trade Lab Terminal

Открытая аналитическая платформа по миру и рынкам: **глобальный режим** (страны, демография, голод, климат, кризисы, торговля,
прогнозы и история, источник под каждым графиком) и **режим портфеля** (мировые котировки из открытых API → признаки → модели →
честный бэктест → риск → оптимизатор → автоторговля на **бумажном счёте**). Никаких брокерских токенов и ключей не нужно;
реальных заявок приложение не отправляет.

## Запуск на Windows
1. Нужен Python 3.10+ (python.org, галочка «Add python.exe to PATH»).
2. Скачай репозиторий и запусти `start.bat`: он создаст окружение, поставит зависимости и откроет http://localhost:8501.
3. Глобальный режим работает сразу, без интернета (данные вшиты). Режим портфеля стартует в **демо** (синтетические котировки),
   пока в базе нет данных: вкладка «ДАННЫЕ» → «Загрузить / обновить данные» (Yahoo Finance, запасные Stooq и Binance, ключи не нужны).
4. Проверка открытых источников у себя: `python scripts/check_sources.py`.

## Глобальный режим «Мир» (по умолчанию)

Переключатель в боковой панели: **🌍 Глобальный мир** / **📈 Портфель и рынки**. В глобальном режиме разделы: ОБЗОР, ИССЛЕДОВАТЕЛЬ
(любой из ~150 показателей на карте/глобусе + лидеры, динамика, CSV), СТРАНА (досье, прогноз показателя с проверкой на истории,
профиль относительно мира), ПУЗЫРЬКИ (анимация в стиле Gapminder), ДЕМОГРАФИЯ (где старше, где сократится население, влияние
на экономику), ГОЛОД (индекс продовольственной уязвимости), КЛИМАТ, КРИЗИСЫ (горизонт 1/3/5 лет), ТОРГОВЛЯ, МОРЕ, КОНФЛИКТЫ,
ГОРИЗОНТ, ВАЛЮТЫ, ИСТОЧНИКИ. **Под каждой картой и графиком показан источник** (название, организация, ссылка, лицензия, дата снимка);
прогнозы ООН помечены как прогнозы, расчёты приложения помечены как расчёты.

Что измерено на реальной истории (не обещания):
- **Статистические прогнозы рядов** (наивный, тренд, демпфированный Хольт, логарифмические варианты): метод выбирается по MASE на
  прошлых прогнозах всех стран; интервалы P10–P90 из эмпирических ошибок; в интерфейсе виден навык против «останется как сейчас»,
  и если навыка нет, об этом сказано.
- **Старение и экономика**: между странами связь видна, внутри страны (фиксированные эффекты, кластерные SE) на этих данных
  статистически не отличима от нуля. Сценарная карта показывает «коэффициент × скорость старения» с интервалом, это не прогноз.
- **Индекс продовольственной уязвимости**: сравнение уязвимости, не прогноз голода. Без компонента недоедания он предсказывает
  недоедание детей через 5 лет с ρ Спирмена ≈ 0.7, но уступает простой инерции (≈ 0.95).
- **Кризисы на несколько лет** (walk-forward 1996–2013, измерено): валютный AUC 0.79 / 0.74 / 0.73 на горизонтах 1 / 3 / 5 лет (наивный признак 0.71 / 0.64 / 0.63);
  инфляционный 0.84 / 0.81 / 0.76 (наивный 0.80 / 0.78 / 0.77, на 5 лет модель не лучше наивного); рецессии 0.63 / 0.55 / 0.57 (хуже или равны наивному: предсказать нельзя).
  Таблица со всеми значениями: вкладка КРИЗИСЫ, файл `assets/crisis_horizon_eval.json`. Конфликты в снимке не оценены (нет данных UCDP).
- Население после 2013 г. в источнике Gapminder задано только точками 2050 и 2100: годовая траектория восстановлена из прироста ООН
  и откалибрована к этим точкам (расхождение ≈ 0%).

Данные: Gapminder/ООН WPP (104 показателя), **хаб Our World in Data (552 показателя из ~190 наборов: демократия, коррупция, образование, неравенство, здоровье, питание, энергия и др., с 1960 года; у каждого указан первоисточник)**, OWID CO₂ и энергия, IMF WEO, World Bank, NOAA/NASA/CSIRO/WGMS (климат); всё встроено в
`assets/snapshot` (обновление: `python scripts/update_global_snapshot.py`). Реестр источников: `tradelab/registry.py`.

## Вкладки (режим «Портфель и рынки»)
- **ОБЗОР**: бегущая строка, тепловая карта рынка РФ, монитор бумаг со спарклайнами.
- **МИР**: 3D-глобус и плоская карта (офлайн): страны по метрике, биржи, потоки «кто кого ведёт».
- **МОРЕ**: танкеры и проливы. Реальные агрегаты IMF PortWatch (проходы по 28 проливам), живые позиции судов
  (Digitraffic в Балтике без ключа, AISStream с бесплатным ключом), условные маршруты танкеров для демонстрации.
- **КОНФЛИКТЫ**: события UCDP GED (загрузка без ключа), карта с очагами, справочник очагов, модель риска начала конфликта.
- **ГОРИЗОНТ (5–10 лет)**: ожидаемая доходность акций и облигаций США, Монте-Карло портфеля со сценариями,
  рост ВВП стран, траектории госдолга. Всё с проверкой вне выборки и явными интервалами.
- **КРИЗИСЫ**: раннее предупреждение по ~190 странам: валютный и инфляционный кризисы, рецессия. Карта риска,
  «Машина времени» (модель видит только прошлое, рядом то, что реально произошло), прогноз, причины, сценарий
  «что если», ожидаемое движение курса с интервалом, проверка вне выборки.
- **ВАЛЮТЫ**: чувствительность 22 валют к доллару, нефти и VIX по реальным данным и сценарии шоков с картой.
- **ТОРГОВЛЯ**: торговые потоки между странами (UN Comtrade или CSV): карта и дуги потоков, сальдо, открытость,
  сеть (PageRank, сообщества), поток Sankey, каналы заражения при кризисе у партнёров.
- **СТРУКТУРА**: остовное дерево, кластеры, теория случайных матриц, топология и хрупкость, режимы, lead-lag, HRP.
- **МАКРО**: ставки ЦБ, валюты, кривая доходности США, сырьё, макро по странам, корреляции классов активов.
- **ОТЧЁТНОСТЬ**: годовая отчётность из SEC EDGAR, импорт CSV.
- **ГРАФИК / РИСК / ФАКТОРЫ / ОПТИМИЗАТОР / СТРАТЕГИИ / МОДЕЛИ / СКАНЕР / АВТОТОРГОВЛЯ**: инструменты по портфелю РФ
  (график, VaR и стресс-тесты, PCA-факторы, Black-Litterman, walk-forward бэктест, paper-торговля с комплаенсом).
- **ДАННЫЕ**: загрузка акций РФ (БКС или MOEX ISS), мировых данных, диагностика источников.
- **ИСТОЧНИКИ**: каталог 40+ открытых источников со статусом и описанием встроенного снимка.

## Качество кризисных моделей (реальные данные IMF и World Bank, проверка вне выборки 1996–2013)
Модель каждого блока лет обучается только на предыдущих годах. Метки событий берутся по данным (Frankel–Rose и др.).

| Событие | AUC ансамбля | AUC «простого признака» | Верхние 10% по риску ловят |
|---|---|---|---|
| Валютный кризис (64 события) | 0.79 | 0.71 | 44% событий |
| Инфляционный кризис (59) | 0.85 | 0.80 | 47% |
| Рецессия (273) | 0.64 | 0.65 | 23% |

Вывод: по валютным и инфляционным кризисам навык заметный, но умеренный; **рецессии не прогнозируются лучше простого
признака**. Интервал P10–P90 для курса покрывает 80% исходов (цель 80%), ошибка медианы 7.4 против 8.6 п.п. у наивной.
Вероятности откалиброваны: в верхнем квинтиле прогноз 8.7% против фактических 6.8% (валюты).
Банковские и долговые кризисы не прогнозируются (нет открытых готовых меток).

## Что можно предсказать на 5–10 лет (реальная история, проверка вне выборки)
| Что | Результат проверки |
|---|---|
| Облигации США, 10 лет | R² 0.89: доходность определяется стартовой ставкой |
| Акции США, 10 лет (по CAPE) | R² 0.08, слабо: оценка сжимается к среднему (вес 0.61), интервалы по реальным ошибкам |
| Рост ВВП стран, 5 лет | на 20% лучше «как последние 5 лет», но от мирового среднего почти не отличается |
| Рост ВВП стран, 10 лет | сверх мирового среднего навыка нет |
Кризисы, войны и рецессии заранее не предсказываются: для них есть сценарии и вероятности рисков, а не прогноз.

## Честно о границах
- Все живые открытые API (Yahoo, Stooq, Binance, MOEX ISS, World Bank, IMF, FRED и др.) написаны по документации и проверены
  тестами на образцах ответов, но не вживую (в среде разработки нет доступа к ним). Проверь у себя `check_sources.py`;
  идентификаторы рядов FRED записаны по памяти, недоступные будут помечены в статусе. Yahoo это неофициальный открытый
  эндпоинт и может ограничивать запросы: тогда срабатывает запасной источник.
- Российской отчётности в открытом API нет: только импорт CSV. Ставки некоторых стран в FRED это ставка дисконта.
- Топология и кривизна это диагностика структуры рынка, а не источник прибыльных сигналов.
- Открытых мировых AIS-данных в реальном времени без регистрации нет: реальные позиции только в Балтике (Digitraffic)
  или по бесплатному ключу AISStream. Маршруты в режиме демо условные, а PortWatch публикуется с задержкой в несколько дней.
- События конфликтов (UCDP) в снимке отсутствуют: пока их не загрузишь, на карте синтетика с пометкой и справочник очагов
  (составлен вручную по состоянию на 2025 год, может устареть).
- CAPE на сегодня оценивается с экстраполяцией (данные Шиллера в снимке до 09.2023, цены S&P 500 до 09.2026).
- Реальных данных о торговых потоках внутри снимка нет (открытых зеркал в GitHub не нашлось): загрузи из UN Comtrade или CSV;
  до этого вкладка ТОРГОВЛЯ показывает демо на гравитационной модели с пометкой.
- Макро в снимке доходит до 2013 года: карта «Машина времени» проверяет модель на истории, а актуальный прогноз
  требует живых данных (кнопка загрузки на вкладке КРИЗИСЫ).
- Реальная торговля намеренно не реализована. Сначала модели должны показать устойчивый результат на бумаге.
- Большинство моделей на ликвидном рынке не лучше случайных; это нормальный результат исследования.
- Ожидаемая доходность и риск считаются по истории и не гарантируют будущего. Не инвестиционная рекомендация.

## Новое: проблемы мира, паспорта стран, настройки
- **ПРОБЛЕМЫ**: тепловая карта «где больше и где меньше проблем» по семи измерениям (голод, здоровье, экономика и бедность, институты и безопасность,
  среда и климат, человеческий капитал, демографическое давление; 30+ показателей). Слои по измерениям, изменение за 5 лет, рейтинг справа от
  карты, матрица стран × измерений, регионы (взвешено населением), связи между проблемами, устойчивость рейтинга к весам.
  Это сравнительный индекс на открытых данных, не прогноз; веса меняются в интерфейсе.
- **ПАСПОРТ**: досье страны: индекс и место, оценка по измерениям с динамикой за 5 лет, профиль против мира и региона, диагноз (сильные и слабые стороны),
  похожие страны, динамика индекса, все показатели с местом, прогноз показателя и досье для печати.
- **НАСТРОЙКИ**: панель подключений (онлайн/ошибка/формат под вопросом, задержка каждого источника, что лежит в локальной базе и до какой даты),
  параметры интерфейса и аналитики (сохраняются в `data/settings.json`), ключи API (в локальный `.env`), сброс кэша.
- **Одна кнопка «Загрузить все онлайн-данные»** в боковой панели: шаги идут параллельно, сбой одного источника не мешает остальным, источник,
  который не отвечает, пропускается быстро; итоговый отчёт по каждому шагу.
- **Маршруты танкеров** в демо-модели теперь идут по воде (растр суши и поиск пути, `scripts/build_sea_routes.py`); раньше заходили на сушу.
  Сопоставление проливов PortWatch с справочником исправлено, окна 7 и 90 суток считаются по календарю.
- Оформление в стиле профессиональных терминалов (янтарный акцент сохранён), карты с рейтингом справа, градиентной шкалой и подсветкой стран.

## Кокпит портфеля (вкладка КОКПИТ, режим «Портфель и рынки»)
Единый взгляд на портфель в духе корпоративных риск-платформ: капитал, VaR/CVaR, просадка, лимиты; разложение по странам риска (ETF на корзины
раскладываются по весам), классам активов и секторам; взвешенные по портфелю показатели стран (голод, CO₂, возобновляемые, коррупция);
вероятности кризисов в странах портфеля (модели раннего предупреждения); факторные сценарии (рынок, нефть, золото, доллар, VIX) с
чувствительностями, оценёнными по истории (МНК, устойчивые SE) и интервалами. Сценарии это арифметика чувствительностей, в стрессе корреляции
меняются. Страна риска задана справочником `config.COUNTRY_OF_RISK` для тикеров универсума, для остальных «н/д».

## Автоматизация и качество
- `.github/workflows/ci.yml`: тесты на каждый push и pull request.
- `.github/workflows/update-data.yml`: раз в неделю (и вручную) скачивает свежие данные и открывает pull request со снимком.
- Страница ИСТОЧНИКИ: возраст каждого показателя, доли рядов с пропусками, скачками и «залипанием», контрольные суммы файлов.
- `python scripts/update_hub.py`: пересобирает хаб Our World in Data (нужен git и интернет, клонирует репозиторий ~300 МБ, снимок ~16 МБ).
- `python scripts/eval_crisis_horizons.py`: измеряет точность кризисных моделей на горизонтах 1, 3 и 5 лет (результат в
  `assets/crisis_horizon_eval.json` и на странице КРИЗИСЫ).
- Не сделано: данные ниже уровня страны (регионы, города), причинные модели с идентификацией, банковские и долговые кризисы,
  голод по IPC/FEWS NET, оповещения.
