# Trade Lab Terminal

Локальный исследовательский терминал: данные БКС → признаки → модели → честный бэктест →
риск-аналитика портфеля → оптимизатор → автоторговля на **бумажном (демо) счёте**.
Реальных заявок не отправляет, токен нужен только на чтение.

## Запуск на Windows
1. Нужен Python 3.10+ (python.org, галочка «Add to PATH»).
2. Скачай репозиторий и запусти `start.bat`. Он создаст окружение, поставит зависимости и откроет `.env`:
   вставь туда `BCS_REFRESH_TOKEN`. Запусти `start.bat` снова: интерфейс откроется на http://localhost:8501.
3. Без токена приложение стартует в **демо-режиме** (синтетические данные), чтобы можно было всё посмотреть.
4. Вкладка «ДАННЫЕ»: «Проверить подключение», затем «Загрузить / обновить данные».

Проверка подключения без интерфейса: `python scripts/check_bcs.py`.

## Вкладки
- **ОБЗОР**: бегущая строка, тепловая карта рынка РФ, монитор бумаг со спарклайнами.
- **МИР**: вращающийся 3D-глобус (работает офлайн): страны окрашены по метрике (рост рынка, ключевая ставка ЦБ,
  инфляция, ВВП, безработица), биржи светятся (открытые пульсируют), по дугам бегут потоки «кто кого ведёт»
  (lead-lag) или сильнейшие корреляции. Таблица 20 мировых бирж со статусом торгов и местным временем.
- **ГРАФИК**: свечи, объём, SMA, Bollinger, RSI/MACD.
- **РИСК**: VaR/CVaR (историческая и параметрическая, Ledoit-Wolf/EWMA), компонентная VaR, вклад в риск,
  корреляции, секторы, просадки, веер сценариев, стресс-тесты, what-if, CSV-отчёт.
- **ФАКТОРЫ**: PCA-факторы, систематический и специфический риск, tracking error, information ratio, альфа/бета.
- **СТРУКТУРА**: карта рынка (остовное дерево, кластеры), шум и сигнал (теория случайных матриц), топология и
  хрупкость (длина MST, коэффициент поглощения, персистентные гомологии H1, риманова метрика между ковариациями),
  режимы рынка, lead-lag и хвостовая зависимость, HRP. Работает на мировых индексах и на акциях РФ.
- **МАКРО**: ставки центробанков, валюты (ECB и ЦБ РФ), кривая доходности США, сырьё и VIX, макро по странам
  (World Bank), корреляции между классами активов.
- **ОТЧЁТНОСТЬ**: годовая отчётность и коэффициенты компаний из SEC EDGAR; импорт CSV для любых других (в т.ч. РФ).
- **ОПТИМИЗАТОР / СТРАТЕГИИ**: минимальный риск, Шарп, mean-variance, risk parity, Black-Litterman на прогнозах
  моделей; портфельный бэктест с ребалансировкой.
- **МОДЕЛИ / СКАНЕР**: walk-forward бэктест без утечки будущего, сравнение моделей, прогноз по всем бумагам.
- **АВТОТОРГОВЛЯ**: сигналы → проверка комплаенса → ребаланс paper-счёта, аварийный стоп, журнал.
  Без браузера: `python scripts/autotrader.py --every 60`.
- **ДАННЫЕ**: загрузка акций РФ (БКС или бесплатный MOEX ISS без токена), мировых данных, диагностика источников.

## Источники данных (все открытые, ключи не нужны)
Yahoo Finance и Stooq (индексы, сырьё), MOEX ISS (акции РФ и IMOEX), Frankfurter/ECB и ЦБ РФ (валюты),
FRED (ставки, доходности), World Bank (макро), SEC EDGAR (отчётность США). Для индексов и акций РФ есть
запасные каналы. Проверить доступность у себя: `python scripts/check_sources.py` или кнопка «Проверить источники».

## Устройство
`tradelab/`: `bcs.py` клиент БКС, `store.py` SQLite, `features.py`, `models.py` (реестр моделей),
`backtest.py`, `risk.py`, `optimize.py`, `strategies.py`, `compliance.py`, `paper.py` (бумажный брокер),
`autotrade.py`, `demo.py`, `sources.py`/`markets.py`/`worlddata.py` (мировые данные),
`structure.py` (топология, RMT, режимы), `globe.py` (глобус), `fundamentals.py`, `views.py`.
Новая модель: класс с `fit(X, y)` и `predict(X)` + строка в `MODELS`. Тесты: `pytest`.

## Честно о границах
- Клиент БКС и все открытые источники написаны по документации и проверены тестами на образцах ответов, но не вживую
  (в среде разработки нет доступа к ним). Проверь у себя `check_bcs.py` и `check_sources.py`; идентификаторы рядов FRED
  записаны по памяти, недоступные будут помечены в статусе.
- Российской отчётности в открытом API нет: только импорт CSV. Ставки некоторых стран в FRED это ставка дисконта.
- Топология и кривизна это диагностика структуры рынка, а не источник прибыльных сигналов.
- Реальная торговля намеренно не реализована. Сначала модели должны показать устойчивый результат на бумаге.
- Большинство моделей на ликвидном рынке не лучше случайных; это нормальный результат исследования.
- Ожидаемая доходность и риск считаются по истории и не гарантируют будущего. Не инвестиционная рекомендация.
