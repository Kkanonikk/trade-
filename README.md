# Trade Lab Terminal

Локальный исследовательский терминал: данные БКС → признаки → модели → честный бэктест →
риск-аналитика портфеля → оптимизатор → автоторговля на **бумажном (демо) счёте**.
Реальных заявок не отправляет, токен нужен только на чтение.

## Запуск на Windows
1. Нужен Python 3.10+ (python.org, галочка «Add to PATH»).
2. Скачай репозиторий и запусти `start.bat`. Он создаст окружение, поставит зависимости и откроет `.env`:
   вставь туда `BCS_REFRESH_TOKEN`. Запусти `start.bat` снова: интерфейс откроется на http://localhost:8501.
3. Без токена приложение стартует в **демо-режиме** (синтетические данные), чтобы можно было всё посмотреть.
4. Вкладка «ДАННЫЕ»: «Проверить подключение», затем «Загрузить / обновить данные».

Проверка подключения без интерфейса: `python scripts/check_bcs.py`.

## Вкладки
- **ОБЗОР**: бегущая строка, тепловая карта рынка, монитор бумаг со спарклайнами.
- **ГРАФИК**: свечи, объём, SMA, Bollinger, RSI/MACD.
- **РИСК**: VaR/CVaR (исторические и параметрические с Ledoit-Wolf/EWMA), компонентная VaR, вклад в риск,
  корреляции, секторная структура, просадки, скользящие бета/волатильность, веер сценариев,
  стресс-тесты, what-if шоки, CSV-отчёт.
- **ФАКТОРЫ**: статистическая факторная модель (PCA), доля систематического и специфического риска,
  tracking error, information ratio, альфа/бета, захват роста и падения.
- **ОПТИМИЗАТОР**: минимальный риск, макс. Шарп, mean-variance, равный вклад в риск, сжатие ковариации,
  взгляды моделей через Black-Litterman; применение к paper-счёту.
- **СТРАТЕГИИ**: портфельный бэктест с ребалансировкой, дрейфом весов и комиссиями.
- **МОДЕЛИ / СКАНЕР**: walk-forward бэктест без утечки будущего, сравнение моделей, прогноз по всем бумагам.
- **АВТОТОРГОВЛЯ**: сигналы → целевые веса → проверка комплаенса до сделки → ребаланс paper-счёта,
  мониторинг лимитов после сделки, аварийный стоп, журнал. Без браузера: `python scripts/autotrader.py`.
- **ДАННЫЕ**: загрузка из БКС в локальную SQLite (`data/market.db`).

## Устройство
`tradelab/`: `bcs.py` клиент БКС, `store.py` SQLite, `features.py`, `models.py` (реестр моделей),
`backtest.py`, `risk.py`, `optimize.py`, `strategies.py`, `compliance.py`, `paper.py` (бумажный брокер),
`autotrade.py`, `demo.py`.
Новая модель: класс с `fit(X, y)` и `predict(X)` + строка в `MODELS`. Тесты: `pytest`.

## Честно о границах
- Клиент БКС написан по документации и не проверялся вживую: если `check_bcs.py` падает, пришли текст ошибки.
- Реальная торговля намеренно не реализована. Сначала модели должны показать устойчивый результат на бумаге.
- Большинство моделей на ликвидном рынке не лучше случайных; это нормальный результат исследования.
- Ожидаемая доходность и риск считаются по истории и не гарантируют будущего. Не инвестиционная рекомендация.

## Безопасность
Токен хранится только в `.env` (в `.gitignore`). Не отправляй его в чаты и не коммить.
