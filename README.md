# Trade Lab Terminal

Локальный исследовательский терминал: данные БКС → признаки → модели → честный бэктест →
риск-аналитика портфеля → оптимизатор → автоторговля на **бумажном (демо) счёте**.
Реальных заявок не отправляет, токен нужен только на чтение.

## Запуск на Windows
1. Нужен Python 3.10+ (python.org, галочка «Add to PATH»).
2. Скачай репозиторий и запусти `start.bat`. Он создаст окружение, поставит зависимости и откроет `.env`:
   вставь туда `BCS_REFRESH_TOKEN`. Запусти `start.bat` снова: интерфейс откроется на http://localhost:8501.
3. Без токена приложение стартует в **демо-режиме** (синтетические данные), чтобы можно было всё посмотреть.
4. Вкладка «ДАННЫЕ»: «Проверить подключение», затем «Загрузить / обновить данные».

Проверка подключения без интерфейса: `python scripts/check_bcs.py`.

## Вкладки
- **ОБЗОР**: бегущая строка, тепловая карта рынка РФ, монитор бумаг со спарклайнами.
- **МИР**: 3D-глобус и плоская карта (офлайн): страны по метрике, биржи, потоки «кто кого ведёт».
- **МОРЕ**: танкеры и проливы. Реальные агрегаты IMF PortWatch (проходы по 28 проливам), живые позиции судов
  (Digitraffic в Балтике без ключа, AISStream с бесплатным ключом), условные маршруты танкеров для демонстрации.
- **КОНФЛИКТЫ**: события UCDP GED (загрузка без ключа), карта с очагами, справочник очагов, модель риска начала конфликта.
- **ГОРИЗОНТ (5–10 лет)**: ожидаемая доходность акций и облигаций США, Монте-Карло портфеля со сценариями,
  рост ВВП стран, траектории госдолга. Всё с проверкой вне выборки и явными интервалами.
- **КРИЗИСЫ**: раннее предупреждение по ~190 странам: валютный и инфляционный кризисы, рецессия. Карта риска,
  «Машина времени» (модель видит только прошлое, рядом то, что реально произошло), прогноз, причины, сценарий
  «что если», ожидаемое движение курса с интервалом, проверка вне выборки.
- **ВАЛЮТЫ**: чувствительность 22 валют к доллару, нефти и VIX по реальным данным и сценарии шоков с картой.
- **ТОРГОВЛЯ**: торговые потоки между странами (UN Comtrade или CSV): карта и дуги потоков, сальдо, открытость,
  сеть (PageRank, сообщества), поток Sankey, каналы заражения при кризисе у партнёров.
- **СТРУКТУРА**: остовное дерево, кластеры, теория случайных матриц, топология и хрупкость, режимы, lead-lag, HRP.
- **МАКРО**: ставки ЦБ, валюты, кривая доходности США, сырьё, макро по странам, корреляции классов активов.
- **ОТЧЁТНОСТЬ**: годовая отчётность из SEC EDGAR, импорт CSV.
- **ГРАФИК / РИСК / ФАКТОРЫ / ОПТИМИЗАТОР / СТРАТЕГИИ / МОДЕЛИ / СКАНЕР / АВТОТОРГОВЛЯ**: инструменты по портфелю РФ
  (график, VaR и стресс-тесты, PCA-факторы, Black-Litterman, walk-forward бэктест, paper-торговля с комплаенсом).
- **ДАННЫЕ**: загрузка акций РФ (БКС или MOEX ISS), мировых данных, диагностика источников.
- **ИСТОЧНИКИ**: каталог 40+ открытых источников со статусом и описанием встроенного снимка.

## Качество кризисных моделей (реальные данные IMF и World Bank, проверка вне выборки 1996–2013)
Модель каждого блока лет обучается только на предыдущих годах. Метки событий берутся по данным (Frankel–Rose и др.).

| Событие | AUC ансамбля | AUC «простого признака» | Верхние 10% по риску ловят |
|---|---|---|---|
| Валютный кризис (64 события) | 0.79 | 0.71 | 44% событий |
| Инфляционный кризис (59) | 0.85 | 0.80 | 47% |
| Рецессия (273) | 0.64 | 0.65 | 23% |

Вывод: по валютным и инфляционным кризисам навык заметный, но умеренный; **рецессии не прогнозируются лучше простого
признака**. Интервал P10–P90 для курса покрывает 80% исходов (цель 80%), ошибка медианы 7.4 против 8.6 п.п. у наивной.
Вероятности откалиброваны: в верхнем квинтиле прогноз 8.7% против фактических 6.8% (валюты).
Банковские и долговые кризисы не прогнозируются (нет открытых готовых меток).

## Что можно предсказать на 5–10 лет (реальная история, проверка вне выборки)
| Что | Результат проверки |
|---|---|
| Облигации США, 10 лет | R² 0.89: доходность определяется стартовой ставкой |
| Акции США, 10 лет (по CAPE) | R² 0.08, слабо: оценка сжимается к среднему (вес 0.61), интервалы по реальным ошибкам |
| Рост ВВП стран, 5 лет | на 20% лучше «как последние 5 лет», но от мирового среднего почти не отличается |
| Рост ВВП стран, 10 лет | сверх мирового среднего навыка нет |
Кризисы, войны и рецессии заранее не предсказываются: для них есть сценарии и вероятности рисков, а не прогноз.

## Источники данных (все открытые, ключи не нужны)
**Встроенный снимок** (`assets/snapshot`, 3.6 МБ, реальные данные): IMF WEO (45 макропоказателей, 1980–2013),
World Bank (ВВП, инфляция, население до 2023), курсы 22 валют (ФРС, дневные с 1971 по 2026), нефть Brent, газ, золото,
VIX, S&P 500, US 10Y. Приложение работает на них без сети. Обновить: `python scripts/update_snapshot.py`.
**Живые источники** (по документации): World Bank API (25 показателей, в т.ч. резервы, внешний долг, кредит, институты),
IMF DataMapper, UN Comtrade (торговля), Yahoo/Stooq, MOEX ISS, Frankfurter/ECB, ЦБ РФ, FRED, SEC EDGAR.
Полный каталог с описанием и статусами: вкладка ИСТОЧНИКИ. Проверка у себя: `python scripts/check_sources.py`.

## Устройство
`tradelab/`: `bcs.py` клиент БКС, `store.py` SQLite, `features.py`, `models.py` (реестр моделей),
`backtest.py`, `risk.py`, `optimize.py`, `strategies.py`, `compliance.py`, `paper.py` (бумажный брокер),
`autotrade.py`, `demo.py`, `sources.py`/`markets.py`/`worlddata.py` (мировые данные),
`structure.py` (топология, RMT, режимы), `globe.py` (глобус и карта), `fundamentals.py`, `views.py`,
`countries.py`, `panel.py` (панель страна-год), `crisis.py` (кризисные модели), `fxscen.py` (валютные сценарии),
`trade.py` (торговые потоки), `catalog.py` (каталог источников), `longrun.py` (оценки на 5–10 лет),
`maritime.py` (суда, проливы), `conflicts.py` (UCDP), `views_global.py`.
Новая модель: класс с `fit(X, y)` и `predict(X)` + строка в `MODELS`. Тесты: `pytest`.

## Честно о границах
- Клиент БКС и все открытые источники написаны по документации и проверены тестами на образцах ответов, но не вживую
  (в среде разработки нет доступа к ним). Проверь у себя `check_bcs.py` и `check_sources.py`; идентификаторы рядов FRED
  записаны по памяти, недоступные будут помечены в статусе.
- Российской отчётности в открытом API нет: только импорт CSV. Ставки некоторых стран в FRED это ставка дисконта.
- Топология и кривизна это диагностика структуры рынка, а не источник прибыльных сигналов.
- Открытых мировых AIS-данных в реальном времени без регистрации нет: реальные позиции только в Балтике (Digitraffic)
  или по бесплатному ключу AISStream. Маршруты в режиме демо условные, а PortWatch публикуется с задержкой в несколько дней.
- События конфликтов (UCDP) в снимке отсутствуют: пока их не загрузишь, на карте синтетика с пометкой и справочник очагов
  (составлен вручную по состоянию на 2025 год, может устареть).
- CAPE на сегодня оценивается с экстраполяцией (данные Шиллера в снимке до 09.2023, цены S&P 500 до 09.2026).
- Реальных данных о торговых потоках внутри снимка нет (открытых зеркал в GitHub не нашлось): загрузи из UN Comtrade или CSV;
  до этого вкладка ТОРГОВЛЯ показывает демо на гравитационной модели с пометкой.
- Макро в снимке доходит до 2013 года: карта «Машина времени» проверяет модель на истории, а актуальный прогноз
  требует живых данных (кнопка загрузки на вкладке КРИЗИСЫ).
- Реальная торговля намеренно не реализована. Сначала модели должны показать устойчивый результат на бумаге.
- Большинство моделей на ликвидном рынке не лучше случайных; это нормальный результат исследования.
- Ожидаемая доходность и риск считаются по истории и не гарантируют будущего. Не инвестиционная рекомендация.
