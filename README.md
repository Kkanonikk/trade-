# Trade Lab

Локальная исследовательская платформа: данные из БКС Trade API → признаки → набор моделей →
честный walk-forward бэктест → прогноз и сканер по списку бумаг. Ничего не торгует (токен только на чтение).

## Запуск на Windows
1. Нужен Python 3.10+ (python.org, галочка «Add to PATH»).
2. Скачай репозиторий и запусти `start.bat`. При первом запуске он создаст окружение,
   поставит зависимости и откроет `.env`: вставь туда `BCS_REFRESH_TOKEN`.
3. Запусти `start.bat` снова, откроется интерфейс на http://localhost:8501.
4. Вкладка «Данные»: «Проверить подключение», затем «Загрузить / обновить данные».

Проверка подключения без интерфейса: `python scripts/check_bcs.py`.

## Устройство
- `tradelab/bcs.py` клиент БКС, `store.py` SQLite (`data/market.db`), `features.py` признаки,
  `models.py` реестр моделей, `backtest.py` бэктест без утечки будущего.
- Новая модель: класс с `fit(X, y)` и `predict(X)` + строка в `MODELS` в `models.py`.
- Тесты: `pytest` (на синтетических данных, проверяют механику, а не прибыльность).

## Безопасность
Токен хранится только в `.env` (в `.gitignore`). Не отправляй его в чаты и не коммить.
